# จัดคู่แบดมินตัน

เว็บแอปจัดคู่ตีแบด แบ่งกลุ่ม A/B สลับคู่อัตโนมัติ มีสกอร์บอร์ด คะแนนสะสม แยกก๊วน และนับลูกแบด

## ติดตั้งบนเครื่อง
- **iPhone / iPad:** เปิดลิงก์ใน Safari > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
- **Android:** เปิดใน Chrome > กด "ติดตั้งแอป" หรือเมนู ⋮ > ติดตั้งแอป
- **Windows / Mac:** เปิดใน Chrome หรือ Edge > ไอคอนติดตั้งในแถบที่อยู่

ข้อมูลเก็บในเครื่องที่ใช้ ย้ายเครื่องได้ที่ ตั้งค่า > สำรอง / ย้ายข้อมูล
